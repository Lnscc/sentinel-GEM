# Marker und Cluster-Marker

## Hypothese

Ein gemeinsames visuelles System aus Signalpunkt, weißem Rand und optionalem
Halo macht einzelne Ereignisse, Cluster und Auswahlzustände auf der Karte
schnell unterscheidbar.

## Umfang

- interaktive Desktop-Demo mit statischer Weltkarte und Beispieldaten
- Einzelmarker, ausgewählter Marker sowie kleine und große Cluster
- Umschaltung zwischen drei simulierten Zoomstufen
- keine echte Karte, Backend-Anbindung oder produktive Komponente

## Start

`index.html` direkt im Browser öffnen. Es ist keine Installation nötig.

## Ergebnis

**Unklar.** Lesbarkeit, Größenstaffelung und Farbcodierung sollen mit dem
Prototyp geprüft werden.

## Tracking
