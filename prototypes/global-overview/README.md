# Globales Lagebild

## Hypothese

Eine karten-zentrierte Übersicht mit priorisierten Ereignissen hilft
Nutzern, relevante globale Ereignisse schnell zu erkennen und nachzuvollziehen.

## Zu prüfen

Nutzer sollen:

- die wichtigsten Ereignisse innerhalb von zehn Sekunden erfassen,
- gebündelte Ereignisse klar von einzelnen Nachrichtenartikeln unterscheiden,
- ein Ereignis nach Region, Zeitraum oder Quelle finden,
- verstehen, warum mehrere Quellen zu einem Ereignis gebündelt wurden.

## Umfang

- Desktop-Übersicht im Light Theme
- große Weltkarte als zentrale Hauptfläche
- mit der Karte verbundenes Kontextpanel, das zwischen Ereignisliste und Details wechselt
- einfache Filter
- intern scrollbare Ereignisliste und Detailansicht im gemeinsamen Kontextpanel
- kein Scrollen des Gesamtdokuments
- realistische statische Beispieldaten

Nicht enthalten sind Mobile, Backend-Anbindung, Dark Mode, Animationen, finale
Markengestaltung und Produktionskomponenten.

## Start

`index.html` direkt im Browser öffnen. Der Prototyp benötigt weder einen Server
noch eine Installation.

## Ergebnis

**Angenommen.** Die verbundene Explorer-Fläche aus zentraler Weltkarte und
wechselndem Ereignis-/Detailpanel wird mit GEM-65 im Monitor umgesetzt.
